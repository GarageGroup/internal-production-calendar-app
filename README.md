## Промт:
Мне нужно подготовить JSON производственного календаря для загрузки в мой сервис.

Параметры:

```text
Страна: <COUNTRY_CODE>
Год: <YEAR>
```

Например:

```text
Страна: RU
Год: 2027
```

Нужно найти актуальный официальный производственный календарь для указанной страны и года, используя надёжные и желательно официальные государственные источники.

Особенно внимательно проверь:

- официальные праздничные дни;
- переносы выходных дней;
- рабочие субботы/воскресенья, если они есть;
- дополнительные выходные;
- сокращённые предпраздничные рабочие дни.

Не ограничивайся стандартным правилом "суббота и воскресенье — выходные", так как производственный календарь может содержать переносы.

Мой сервис самостоятельно создаёт базовый календарь:

```text
Понедельник-Пятница -> WorkingDay
Суббота-Воскресенье -> Weekend
```

Поэтому в JSON необходимо включить **только исключения из этого стандартного правила**.

Допустимые типы:

```text
WorkingDay
Weekend
Holiday
ShortenedDay
```

Значения означают:

```text
WorkingDay   - рабочий день, который по стандартному календарю был бы выходным
Weekend      - дополнительный/перенесённый выходной день
Holiday      - официальный праздничный нерабочий день
ShortenedDay - сокращённый рабочий день
```

JSON должен иметь строго следующий формат:

```json
{
  "country": "RU",
  "year": 2027,
  "days": [
    {
      "date": "2027-01-01",
      "type": "Holiday",
      "comment": "Новый год"
    },
    {
      "date": "2027-02-20",
      "type": "WorkingDay",
      "comment": "Перенос рабочего дня"
    },
    {
      "date": "2027-02-22",
      "type": "Weekend",
      "comment": "Перенос выходного дня"
    },
    {
      "date": "2027-04-30",
      "type": "ShortenedDay",
      "comment": "Предпраздничный сокращённый рабочий день"
    }
  ]
}
```

Требования:

1. Формат даты строго `yyyy-MM-dd`.
2. `country` — переданный мной код страны.
3. `year` — переданный мной год.
4. `type` может содержать только:
   - `WorkingDay`
   - `Weekend`
   - `Holiday`
   - `ShortenedDay`
5. `comment` должен кратко объяснять причину исключения:
   - название праздника;
   - перенос рабочего дня;
   - перенос выходного;
   - предпраздничный сокращённый день.
6. Не добавляй обычные рабочие понедельник-пятница.
7. Не добавляй обычные субботы и воскресенья.
8. Добавляй субботу/воскресенье только если она официально стала `WorkingDay`.
9. Добавляй будний день с типом `Weekend`, если он официально стал дополнительным выходным.
10. Официальный праздничный день помечай как `Holiday`.
11. Сокращённый рабочий день помечай как `ShortenedDay`.
12. Один день должен присутствовать в JSON не более одного раза.
13. Все даты должны принадлежать указанному году.
14. Перед выдачей результата проверь JSON на валидность и отсутствие дубликатов.
15. Не придумывай данные. Если официальный календарь на этот год ещё не утверждён или есть неоднозначность — явно сообщи об этом и не подменяй данные предположениями.

## 2026-10-06 — Исправления ревью инкремента 2: FlatArray

**Решение пользователя:** почти не использовать обычные массивы; основной тип последовательностей — FlatArray, как в проекте-образце.

**Выполнено:** изучены FlatArray для headers, CurrencyPairs, конфигурационной проекции и AsyncPipeline в образце; проверены исходники установленной версии 1.5.1. Обновлены AGENTS.md, архитектура, спецификация, план и обзор проекта.

**Самостоятельно принято:** nullable-обёртка FlatArray в JSON DTO сохраняет ошибку для days:null, поскольку встроенный конвертер не-nullable FlatArray иначе превращает null в пустую коллекцию. Это не изменение бизнес-контракта. Для LINQ/xUnit использовать AsEnumerable без копирования; Dictionary оставить как структуру уникальных overrides по дате. Правило обычных массивов — конкретные исключения внешних API с записью основания, а не абсолютный запрет.

**Заменённые решения:** предыдущие обычные массивы генерации/DTO/fixtures и ToArray в тестах больше не используются; исторические записи выше отражают первоначальный вариант инкремента.

**Проверки:** Release build — 0 ошибок/предупреждений; 74 теста пройдены, 0 ошибок и пропущенных, включая days:null, days:[], null-элемент и граничные годы. Поиск в C# src/test не обнаружил обычных массивов и ToArray.
